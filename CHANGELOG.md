# Change Log

All notable changes to this project will be documented in this file.
See [Conventional Commits](https://conventionalcommits.org) for commit guidelines.

## [0.1.6](https://github.com/organigram/organigram/compare/v0.1.5...v0.1.6) (2026-07-20)

- Added the initial `@organigram/passkey-wallet` package.
- Added WebAuthn registration and unlock helpers, including server-side challenge verification, credential management, and encrypted vault envelope support.
- Added wallet cryptography, vault, and recovery phrase helpers for a standard EOA unlocked by passkeys.
- Added an EIP-1193 provider and RainbowKit wallet adapter for dapp integration.
- Added package tests, build output, documentation generation, and README usage examples.
